# 输入与证据接口

## 输入与补牌

CLI 接受一个牌数组，或含 `spread` 的对象。位置沿原牌阵命名，主位名称保持唯一；逐张填写原包中已确认的正逆位，使用 JSON 布尔值。原材料缺项时，先核对已有抽取记录再构造输入。

```json
{
  "spread": [
    {"position": "Pos 1 [我的状态]", "card_name": "The Magician", "reversed": true},
    {"position": "Pos 2 [他的状态]", "card_name": "Ace of Cups", "reversed": false}
  ],
  "supplements": [
    {"for_position": "Pos 1 [我的状态]", "card_name": "Eight of Swords", "reversed": false}
  ]
}
```

补牌也可放在 `spread` 内，标 `supplement: true`，用 `parent_position` 指向主位；旧的 `position: "Supp: Pos 1"` 可按唯一 Pos 编号解析父位。同一补牌在输入中保留一份；发现两个渠道重复提供同一父位的同名牌时，核对原始记录再继续。

输出 `per_card` 保留原属性，另列 `role`、`parent_position`、`working_eligible`。`spread_synthesis.counts` 统计主牌的元素、质量、源质及柱；`participation` 给出统计口径、主位与补牌列表。补牌仍逐张展开，其说明落回父位。主牌相同牌名出现在不同合法位置时，按不同抽取单元保留。

调用方已验证的旧 Phase 3 包可直接复用；缺少新增参与字段时，根据原始主补标记及父位区分参与资格，保留原属性。结构输出沿调用方 schema 表达同一 SOP：例如兼容结构字段 `exclusions` 的每项由 `disposition` 标为 `excluded`、`retained` 或 `undetermined`，关系放入 `phase35.relations`。调用方仅提供已列明的固定来源时，图像分支留待实际材料可用的入口。

## 材料的来源

| 材料 | 可说明什么 | 记录方式 |
|---|---|---|
| 原始抽取 | 抽到哪张、哪位、什么方向 | 牌位＋原包 |
| Book T 映射、源质、旬星 | 指定体系中的属性 | raw 字段或展开层＋精确引文 |
| 已查看的图像 | 本图中实际可见的动作、位置、物体 | 牌组／版本＋图像路径或来源＋可见事实 |
| 用户的描述或校准 | 用户明确提供的情境与对应 | 标为用户材料，保留其确定程度 |
| 元素方法卡 | 怎样检查关系 | 方法名＋适用理由 |
| 关系候选 | 这些材料可能如何组合 | 两端材料＋连接理由＋支持边界 |

同一卡片的元素、质量、展开句与方法转述属于同一抽取单元。可列出多个属性帮助理解，来源计数沿原始单元追溯。

## 按需图像读取

当问题直接涉及牌的核心动作，或属性层难以区分资源归属、运动方向、中心与背景时，查看已确认牌组的对应图像或已核对资料，再提出图像候选。

先记录可见事实，如“人物在河这一岸，树木在对岸”；再记录推演，如“成果尚未抵达人物这侧”。图像所示的当前位置与未来结果分别判断。只有牌名或 `compound_image` 时，继续读已有属性；具体图像分支留待材料补足。

用户明确提供的图像描述或本轮情境对应可参与解释，并保留用户来源与确认程度。RWS 格式名称只用于映射 Book T ID；使用韦特、托特、马赛或其他牌面时，各自标记图像版本。核心内容优先引用现有 `raw_correspondences.book_t_summary`，方法卡中的例子作为有条件的示范。

图像判断可沿两条简单线索展开：中心、连线和人物互动说明谁正在做事；外围实体说明作用条件。土的封存与加工、土的生长与循环，也依本图及所用牌组分别检查。单个符号的名称不足以决定它在全图中的功能。
