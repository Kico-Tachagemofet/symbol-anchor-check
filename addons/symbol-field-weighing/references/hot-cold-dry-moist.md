# 冷热干湿：共同性质、融合与转化

用来解释元素怎样相接、怎样共同维持一种处境，以及改变可以从哪里发生。先拆开每个元素的两项性质，再看它们在本盘中如何作用。

## 性质与元素

**热**推动改变、向往与行动；**冷**维持已定条件或持续体验。**湿**向周围传递、感染；**干**保有自身的确定内容，所做之事落在其处，对外传递有限。干湿讨论传递与保有，精锐／晦暗讨论目的怎样明晰。

| 元素 | 自身性质 | 接向后续元素的中介性质 | 作用提示 |
|---|---|---|---|
| 火 | 热 | 干 | 动力指向一项具体内容 |
| 土 | 干 | 冷 | 实事、资源与结构持续存在 |
| 水 | 冷 | 湿 | 体验持续，并浸润周围 |
| 风 | 湿 | 热 | 观念、联络扩展并推动变化 |

性质描述作用方式：害怕失败可以推动行动，持续的快乐也可以感染周围；冷热分别落实到当前内容。

## 四种读法

| 关系 | 框架 | 在本盘怎样用 |
|---|---|---|
| **共同性质** | 火土同干，土水同冷，水风同湿，风火同热 | 找各位置具体共享什么，再看叠加后的全场特点 |
| **相对** | 火水、风土的两项性质均不同 | 说清两端怎样难以直接相接，并保留各自真实内容 |
| **融合** | 中介可各取两端的一项性质，使不同内容共存 | 看中介怎样维持结构；共存可能支持合作，也可能维持纠结 |
| **转化** | 保留一项性质，改变另一项，形成新的配置 | 原问涉及改变时，指出现有条件中可用的转向 |

| 转化路线 | 保留什么 | 改变什么 |
|---|---|---|
| 火（热干）→土（干冷） | 干 | 热→冷 |
| 土（干冷）→水（冷湿） | 冷 | 干→湿 |
| 水（冷湿）→风（湿热） | 湿 | 冷→热 |
| 风（湿热）→火（热干） | 热 | 湿→干 |

**小例一：共同的干。**星币三、星币四与权杖六逆的例子中，人确有技术、守护的资源和做过的事，别人却未必接收到。共同的干把问题引向“这些内容怎样被传达”；是否缺乏能力是另一项判断。

**小例二：中介也会维持僵局。**宝剑骑士逆、星币五与圣杯四的例子，以风的湿与土的冷形成水：联络与已有处境被感受粘在一起，令人不满却仍纠结。可另取风的热与土的干，形成火：将当下需要化为直接行动，并利用已有陪伴条件。行动方式改变后，关系可能改善，也可能走向分开，具体结果另看材料。

把实际采用的关系及位置依据写回共振／张力。融合说明怎样共存，转化说明配置怎样改变；提出的转化方案作为建议保留，已发生的变化由本盘材料确认。

原典参照：亚里士多德《论生成与消灭》[卷二第 2–4 章](https://classics.mit.edu/Aristotle/gener_corr.2.ii.html)的性质配对与元素互化；阿格里帕《隐秘哲学三书》[卷一第 3 章](https://esotericarchives.com/agrippa/agrippa1.htm)的自身／中介性质排列。场景解释及牌例属于塔罗应用。
