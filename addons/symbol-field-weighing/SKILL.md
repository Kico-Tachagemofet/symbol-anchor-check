# 场域称重 v4.2

这是本包随附的场域称重模块，位于 [anchor-check](../../SKILL.md) 的 Phase 3 与 Phase 4 之间，每盘执行。输入为原始符号包、逐牌属性与汇总、原问、六位职责、当事人视角。

## 为什么需要整场称重

逐张展开属性能保证每张牌有据，却不能自动决定这盘最重要的内容。逐位写答案再拼接，容易让张力成为零散分析的副产品，让漂亮的单牌压住全场，或者把状态、语气和真正回答的问题摊成同等权重。

人类读牌常先看见整个场，再理解局部。对 LLM，Phase 3 先提供可回查的资料，随后才做这种有据的整体判断。它要保留的是 **先看整场、再落单张** 的能力。识别每张牌的内容和可能施动者属于认识材料，暂时不替每个位置定出完整情境答案。

元素框架帮助说清整场怎样运作：风的连接、火因水果、水影响土解释关系；三性质与冷热干湿解释参与方式和转化；能量模型辨认功能偏重及组合的能力与代价。它们进入整体印象、共振与张力的判断。

## 重心怎样形成

| 动作 | 实际要做什么 | 产物怎样进入下一步 |
|---|---|---|
| **illustrate 整场** | 把所有主位当一幅画：属性、核心内容与元素怎样同时出现、怎样相接？ | 一个暂定的整体场景；列出形成这个印象的材料 |
| **locate 问题与位格** | 这次问什么？每个位置在此问题中承担什么职责？ | 确定场景中哪些部分真正回答原问，哪些只是背景或语气 |
| **当事人 lens** | 从谁的视角看这个场？同一姿态落在不同主体身上，意义怎样改变？ | 形成承重落点：场往哪沉 × 原问 × 当事人视角 |
| **共振与关系复核** | 哪些位置共享属性或共同参与一个作用？关系模型能解释什么差别？ | 检验整体印象，必要时修正重心 |
| **张力与语言边界** | 表面印象和底层机制有什么差异？哪部分仍真实成立？ | 指定答案能落实到什么主体、对象、程度与范围 |
| **显著度** | 在这些已经看清的材料中，什么对本轮问题最重要？ | 暂定主梁与次要内容，交给 Phase 4 检验与表达 |

这是一条生成与回看的路径。重心与共振各有职责，分别输出；它们不由计数自动排序，也不由六个局部结论相加得到。

## 怎样使用元素方法

在 illustrate 形成整体印象，以及共振／张力复核时，依实际疑点选用下面的框架表和短例。把有用的判断与牌位依据写进原有输出，篇幅随本盘需要展开。

| 整场出现的疑点 | 方法入口 | 应带回本盘的解释 |
|---|---|---|
| 信息、评价、人物、感受或资源之间存在联系／干扰 | [element-relations.md](references/element-relations.md) 的风连接 | 哪两端被怎样接通，什么被传递或扰动 |
| 行动／起因与感受／受用相接 | 同卡的火因水果 | 谁做了什么，使谁怎样回应；具体连接依据 |
| 感受、关系或往来改变现实条件 | 同卡的水影响土 | 土自身的条件与来源保留，说明它受到何种改变 |
| 同样“主动”“被动”“难受”却表现不同 | [three-properties.md](references/three-properties.md) | 精锐／晦暗、稀薄／致密、运动／静止怎样造成差别 |
| 同质、相对、融合与转换需要解释 | [hot-cold-dry-moist.md](references/hot-cold-dry-moist.md) | 两性质分别作用，哪个共享性质充当中介，当前组合产生什么结果 |
| 单元素功能偏弱／强化，或元素组合明显；原问关心平衡与持续性 | [element-combinations.md](references/element-combinations.md) | 单元素缺乏／强化、风火与水土、另四组组合的能力和代价；按本盘材料取其适用面 |

框架表供分析时查用，结论沿用原有共振／张力项呈现。关系用一句话写清主体、两端材料和连接理由；不同模型保留各自定义。框架原理提供读法，当前材料支持本次判断。

## 材料怎样参与

| 材料 | 参与范围 |
|---|---|
| 主牌 | 整场共振与跨位 working，按六位职责落实 |
| 补牌 | 保留全部属性，澄清父位内容；跨位关系仍由主位承担 |
| 宫廷复合元素 | 分清外层作用方式与内层场域，比较时标出所读层 |
| 奇迹牌 | Aether 单列，核心与主锚在相应层参与，随后经 Q1/Q2 |
| 骰子、易经、字卡 | 以各自系统进入全场核对，保持来源；后续复核时说明实际新增部分 |
| 已核对图像／用户校准 | 依 [输入与证据接口](../../references/input-and-evidence.md) 使用，保留牌组与来源 |

同一张牌的元素、质量、展开句与模型转述可以共同解释它，但属于同一抽取单元。列重心依据时沿原始单元追溯；至少三项不同单元相合时明确列出，支持较少时直接说明暂定范围。

## 共振、张力与显著度的辨析

共振先指出“共享了什么”，再解释这些位置怎样合成一个质。例如接受性分布在状态与态度上，仍要看位格和其他层，才能说明接受的是哪件事、以什么方式发生。

张力用于限定语言。某种积极或安稳印象被降权时，继续说明其中真实的信号落在哪；它可能只是对象不同，也可能只是范围有限。逆位先保留内容，再辨认其表达与施动者，避免把全逆读成所有内容普遍消失。

显著度围绕原问判断。姿态有时承载另一个独立内容，有时安抚、拒答或划界本身就是答案。两者并排考察，按本盘确定；主问题的重要程度与机制的确定程度分别记录。

## 输出给 Phase 4

```markdown
## Phase 3.5 场域称重

- **场景**：[一句整场的画／调／作用；贡献材料]
- **重心**：[承重落点；场景×原问×视角怎样形成它]
- **共振组**：[具体位×位 → 共享属性／所用框架 → 合并后的质；涉及关系时说明两端怎样相接]
- **张力／假面**：[表面与底层；所用框架揭示的差异或代价；仍真实成立的信号及其落点]
- **语言边界**：[可以说清什么，哪些具体指涉仍保持开放]
- **暂定显著度**：[主梁 → 次要内容；与原问的关系]
```

Phase 4 按显著度检验候选，继续比较排除／保留／未定；跨符号核对或 Q2 带来新发现、分流变化时回看称重。answer 回应主问题的支持范围，未决机制保持清楚。可选口吻段落只承载最终 answer，并继承这里形成的显著度与语言边界。

称重显式给用户看，继续在新盘中校准。历史案例重分析与新的独立表现分别记录；维护方法时参阅 [CHANGELOG](../../CHANGELOG.md)，日常解读依本入口与实际所用方法卡完成。
